# ChronosImage AI

## Overview

ChronosImage AI is a browser-based storyboard and sequential image
generation interface designed to help users create visually consistent
multi-scene stories. The application provides a modern UI for defining
characters, selecting art styles, generating the first scene, and
extending subsequent scenes while maintaining visual continuity.

> **Note:** This project is a front-end interface. Image generation
> requires valid access to the Google Gemini / Imagen APIs.

------------------------------------------------------------------------

## Features

-   Modern responsive interface (Tailwind CSS)
-   Character and world-building configuration
-   Multiple built-in art styles
-   Sequential storyboard generation workflow
-   Image upload as the first reference frame
-   AI prompt enhancement
-   Storyboard timeline management
-   Image preview and lightbox
-   Slideshow playback
-   Storyboard export
-   Project import/export (JSON)
-   Automatic local browser saving
-   Retry mechanism for API requests

------------------------------------------------------------------------

## Requirements

-   Modern web browser
-   Internet connection
-   Google Gemini / Imagen API access
-   JavaScript enabled

------------------------------------------------------------------------

## How to Use

1.  Open `Pasted code.html` in a modern browser.
2.  Enter the character description.
3.  Choose an art style.
4.  Describe the first scene or upload a reference image.
5.  Generate the first frame.
6.  Continue creating new storyboard frames.
7.  Save or export your project when finished.
